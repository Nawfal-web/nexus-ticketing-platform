NexusTickets

A modern web-based ticketing platform built with React, TypeScript, and Vite.

NexusTickets is a web development project designed to provide an accessible and intuitive platform for ticket-related activities, with a focus on modern UI design and user experience.

Project Status: Under Development

Overview

NexusTickets aims to simplify the ticketing experience through a modern web interface and organized application architecture.

Tech Stack

- React  User interface development
- TypeScript Type-safe application development
- Vite Development server and build tooling
- CSS Application styling
- Gemini API AI integration (where configured)

Getting Started

 Prerequisites:

- Node.js
- npm

 1. Clone the repository


git clone https://github.com/Nawfal-web/nexus-tickets.git


 2. Enter the project directory

cd nexus-tickets


 3. Install dependencies

npm install


 4. Configure environment variables

If your application uses Gemini API functionality, create a `.env.local` file in the project root:

GEMINI_API_KEY=your_api_key_here

Never commit your actual API key to GitHub.

 5. Start the development server

npm run dev

Open the local URL displayed in your terminal.
